# Project facts

## Name
Minotaur

## Domain
Climbing gym app for the climbing club Minotaur.

## Languages
- English (`en`): default, used for code and all user-facing text.
- Croatian (`hr`): translation, added later.

## Data sensitivity
- Basic member data: names, emails, phone numbers.
- Minors: minors are members like any other, with an additional parent or
  guardian field.
- Payment data: membership fees.
