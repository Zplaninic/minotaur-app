# Project facts

## Name
Minotaur

## Domain
Climbing gym app for the climbing club Minotaur.

## Languages
- English (`en`): default, used for code and all user-facing text.
- Croatian (`hr`): translation, added later.

## Data sensitivity
- Basic member data: names, emails, phone numbers, birthdays, tax numbers.
- Minors: minors are members like any other, linked to one or more guardians.
- Guardian data: names, emails, phone numbers.
- Payment data: membership fees.
